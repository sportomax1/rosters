# Changelog

## v0.1.0 — 2026-07-24

### Added

- Local-only `SYS-DATA` file loading
- Original-versus-modified binary comparison
- Changed-byte and region counts
- Configurable difference-region grouping
- Synchronized hex inspection for files A and B
- Highlighting for changed and selected bytes
- Search for ASCII, hex bytes, and 8/16/32-bit integers
- Experiment notes
- JSON difference-report export
- Responsive mobile and desktop interface
- Initial file-format research documentation
- Repository protections against committing real save files
- GitHub Pages deployment workflow

### Known limitations

- No PS3 save decryption or resigning
- No confirmed NCAA Basketball 10 roster schema
- No roster write-back capability
- No player or team table until fields are mapped
